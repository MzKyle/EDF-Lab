# 花粉数据到达后的实验方法

先选一组代表性视野，覆盖纹理丰富、低对比度、明显离焦和空白情况。核对图像尺寸、Z 层范围、真实间距和曝光条件。运行 `FS_Default`，再逐项比较配准、光度补偿、一致性过滤和降噪。打开对应 Helicon 图及原始焦层，记录光晕、真实边缘、低对比纹理和形态的人工观察。

## 焦层消融

| 策略 | CLI 参数 | 实验意义 |
| --- | --- | --- |
| 全部 | `--sample all` | 全焦层基线 |
| 间隔 | `--sample stride --step 3 --offset 0 --offset 1 --keep-endpoints` | 两个起始偏移，保留原始覆盖，端点间隔可能缩短 |
| 连续范围 | `--sample range --range 10 30` | 按采集序列连续取层，缩小覆盖范围 |
| 指定列表 | `--sample list --layers 1 5 9 12` | 使用明确的实际 Z 编号 |
| 均匀目标层数 | `--sample uniform --count 50 --count 25 --count 17 --count 13 --count 10` | 对 50 层输入近似均匀选取并固定首尾 |

抽层以已采集的排序为基准。编号有缺口时，实际数字间隔以 Manifest 为准。`--keep-endpoints` 可将源焦栈两端加入间隔、范围或编号选择。连续范围研究应保留该选项的关闭状态。记录中保存实际 Z 编号、相邻差、覆盖范围和可用时的 µm 坐标，分别标记覆盖范围和采样间距的改变。融合参考层索引是**抽层之后**传给引擎的零基索引。

## ROI 与指标

两侧默认各自选择 ROI。掌握图像间几何关系时，可通过 **ROI 对应** 输入右图到左图的 X/Y 比例、像素偏移及各自有效区域。该映射覆盖平移、裁剪及轴向缩放。旋转、变形或未知有效区的结果可人工分别框选后查看。ROI 区域始终在各自图像坐标内，配准或裁剪后应核对是否覆盖同一标本区域。原始焦层曲线复用同一个相机像素窗口，观察曲线时也应结合原图是否有位移。

评价以 OpenCV 灰度亮度计算。8 位像素使用 0–255 量级，16 位无符号值先线性转换至相同量级。ROI 坐标从左上角 `(0, 0)` 起，大小以像素为单位。

| 指标 | 定义与单位 |
| --- | --- |
| Laplacian Variance | 四邻域拉普拉斯响应的总体方差，单位为灰度级² |
| Tenengrad | 3 × 3 Sobel 水平与垂直梯度平方之和的像素均值，单位为灰度级² |
| SML | 水平和垂直二阶差分绝对值的总和，量级为灰度级 × 像素数。`SML / px` 为归一化均值 |
| 亮度均值、标准差 | 灰度亮度的均值和总体标准差，单位为灰度级 |
| 饱和比例 | 至少一个颜色通道触到 0 或 255 的像素比例，范围 0–1 |
| 背景噪声估计 | 在分布式候选块中选取最低梯度的至多五块，计算各块拉普拉斯残差的 `1.4826 × MAD / sqrt(20)` 后取中位数，单位为灰度级。ROI 短边小于 8 像素时留空。记录包含使用的区块 |
| 输出尺寸 | PNG 解码所得的宽高，以像素记录 |
| 融合耗时 | 原生子进程启动、运行和回收的墙钟秒数。输入预检和图像指标计算在其范围之外 |
| 峰值 RSS | 每约 80 ms 对进程树成员 RSS 求和，保留观测最大值，记录单位 B。共享页可能计入多次，短时峰值可能落在采样之间 |

上述空间导数指标也会对噪声和增强造成的高频响应敏感。比较时结合亮度、噪声、视野覆盖、裁剪、每个区域的原始焦层及人工观察。对不同尺度或未经配准的图像采用对应 ROI 的独立测量与外观核查。焦层图是上游从输入焦序估计的相对深度，可辅助定位变化区域。物理 Z 坐标保存在索引和 Manifest 中。

先在少量真实视野理解主要失效模式，再用已确认参数运行完整采集批次，结合报告和人工 ROI 记录分析。当前模拟样本用于验证软件和原生进程流程，真实光学表现和 Helicon 对照结论留待真实采集数据。
