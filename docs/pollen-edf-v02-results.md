# PollenEDF V0.2 实拍研发记录

## 试验基线

本轮在本机备份上按采集日期拆分。开发包含 5 个视野和 146 张原图，覆盖近空白、密集花粉、低对比、明显失焦和高亮环状边缘。留出包含其余 4 个日期的 4 个视野和 120 张原图，这四个视野均未进入 V0.1 的融合对照。样本规模支持逐案例核验。

对照使用原始焦层的整序列和相同的输入哈希。选定相机坐标内区并保留每张结果的匹配坐标。Helicon Focus 8.1.0 B 按原设置复跑，以无压缩 TIFF 保存并无损转换成比较用 PNG。官方 focus-stack 1.5 发布制品仍按锁定哈希运行。原生进程的 OpenCV 证据为 OpenCL 不可用。裁片中另以强制 CPU 跑实测，PollenEDF 的 CPython 工作进程使用 CPU。

## 原生单因素实验

5 个开发视野每个运行 14 组。默认与显式一致性 2 的输出哈希逐视野相同。一致性 0 和 1 在四个有花粉的暗区都留下更多高通残差。全局配准中位耗时上升到 36.67 秒，默认是 24.44 秒。全分辨率配准的中位峰值 RSS 为 7369 MiB，默认约 3707 MiB。两种配准变体都保留了可见的亮点轨迹。

默认的独立暗区高通 RMS 中位数为 1.361。单独关闭配准降到 0.996，降噪 64 降到 0.638。强降噪削弱小系数，保留配准的条件下仍存在部分亮点轨迹。组合调优据此选择关闭配准及降噪 64，使用同一官方二进制实跑。 [单因素计划与记录入口](reports/2026-11-27-pollen-edf-v02/dev-native-ofat.json)

这些证据支持将固定相机坐标上的真实像素选择作为自主路线。官方原版的成片、日志和 SHA-256 用作对照，当前研究用参数对照和中间图定位上游行为。

## 自研消融与修订

| 观察 | 开发集实测 |
| --- | --- |
| 暗背景平均 | 首版 Adaptive 的独立暗区高通 RMS 中位数是 0.361，关闭背景处理后为 0.676。近空白视野中 Helicon 是 1.039，Adaptive 是 0.363。等增益照片中 Helicon 的点状长痕明显，自研结果的暗区更均匀。 |
| 重复孤立亮点 | 在 11-05 稀疏低对比视野中开启后，暗区高通 RMS 从 0.405 降至 0.361。小颗粒窗口中央的弱亮斑保留，左侧轮廓在硬选择下更容易出现块状跳变。 |
| 噪声感知与焦层优化 | 关闭噪声感知后，4 个结构窗口中有 3 个的原焦层边缘相关下降。边缘感知优化使 4 个窗口的这一相关值小幅提高。它们是原片相似性检查，可与不同焦层结构的保留同时解读。 |
| 评分和软融合 | SML 与 Tenengrad 硬选择有强烈的跳层痕迹。首版 Adaptive 的单尺度试验在这四个结构窗口中取得更高的单帧边缘相关。多尺度评分的普适优势仍待更多数据。降低局部置信度时的软融合改善过渡。两级金字塔减轻了短栈块状边缘，耗时从首版的 14.08 秒上升到 21.61 秒。 |
| 间隙修正 | 在 10-29 密集视野，原片 7×7 间隙样本的灰度中位数为 12/15/14。首版 Adaptive 得到 70/61/55，修订后回到 10/10/9。三个颗粒内部点改前改后的灰度同为 178/127/138。三个间隙的逐层测量都有较暗中段和较亮端部。 [观测位置与逐层亮度](reports/2026-11-27-pollen-edf-v02/gap-review/measurement.json) |
| 极低置信回退 | 宽峰候选池在 26 层短栈的全图平均占比约 0.7%，块状问题依旧明显。随后在弱栈中启用代表性原片，实测使用了零基索引 13，约 55.7% 的像素权重来自这一回退。原有模糊保留，跳层形成的假边界显著减弱。其它 4 个开发视野的结果与单独开启间隙修正时逐文件哈希相同。 |

关闭配准加降噪 64 的原生组合在开发集测得暗区高通 RMS 中位数 0.233，自研冻结方案是 0.361。较低 RMS 需要结合原始焦层和颗粒纹理判断。自研冻结方案的峰值 RSS 中位数约 650 MiB，同期原生调优组约 4452 MiB。

冻结方案启用离焦间隙修正与弱栈单层回退。宽峰增强和金字塔保留为独立可选项。 [参数与源代码锁定记录](reports/2026-11-27-pollen-edf-v02/locked.json) · [开发集全量指标](reports/2026-11-27-pollen-edf-v02/dev-measurements.csv)

## 结论

花粉专项方案值得继续作为低内存研究路线，当前证据不足以替换 Helicon。已验证的模块收益集中在暗背景跨层处理、固定亮点的局部抑制、开发样本的特定间隙和全图极弱时的保守回退。留出曲线表明，最迫切的质量问题是低置信区域内的焦层跳变。局部连贯分配和局部回退需要在新的留出视野上检验，尤其是密集低对比和明亮外壁。对于采集未覆盖的结构，仍需扩充采集焦程。对照使用已有备份中的不同日期样本，范围为这台设备的 9 个视野。YOLO 识别验证留待模型和标注固定后进行。
